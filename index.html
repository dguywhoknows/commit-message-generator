The app itself, running inside this page. Anything you do here is saved in your browser.

Ask it to do things

Press Ctrl+K in the app (Cmd+K on a Mac) and describe what you want. The model chooses from the app's own functions, runs them in order and tells you what changed. Some examples:

Write the commit message, and mention it fixes issue 42Writes the message with the issue reference.
Split this into separate commitsGroups the files and writes a message for each.
Our team requires a scope on every commitUpdates your conventions so the linter enforces it.

Instructions you save in the same box, such as "keep it short" or "I'm a beginner", are added to every AI request the app makes.

Features

Unified diff parser
New/deleted/renamed files, hunks, old/new line numbers, binary detection.
Collapsible diff viewer
With add/delete stats and change bars.
Local commit-type
Scope inference (whitespace-only → style, lockfiles → build, tests → test …).
AI commit messages
In Conventional Commits / Gitmoji / plain style, with optional 'why' context.
Live message linter
72-col subject/body, imperative mood, conventional prefix, blank line, specificity.
AI PR description
Summary, Changes, How to test, Risks, Checklist.
AI code review with severity, file
Line and suggested fixes.
Token-budgeted diff packing
Lockfiles omitted, docs/deps last.
Pre-commit checks on added lines
Likely secrets (AWS keys, private keys, tokens, hard-coded passwords), committed .env/key files, merge-conflict markers, debug statements, focused tests and new TODOs.
Split page
Groups a large diff into focused commits (tests travel with the code they cover; docs, dependencies and CI separate), writes a message per group, and produces a ready-to-run git add / git commit script.

Runs in your browser

Diff parsing, viewer, type/scope heuristics, linting, prompt packing, git command builder. None of this needs a network connection or a model.

Uses a language model for

Commit message generation guided by local type/scope heuristics. PR description generation. Structured code review over the changed lines.
